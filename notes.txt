A packet is the following:
    [NetworkPacket]
    name: string,
    timestamp: SystemTime,
    raw: vec<u8>
    layers: vec<layer>

    [Layer]
    Contains the layer type, name and fields.
    For TCP this would be OsiLayer::Transport, name: "TCP Packet", and TCP fields
    Each layer of the OSI Model should make a layer object

    [Field]
    A field with name and value

[TcpStream]
src: (IpAddr, u16),
dst: (IpAddr, u16),
buffer: BTreeMap<u32, Vec<u8>, tree of all the segments of the TCP stream

[IpFragmentedPacket]
id: u16,
source: IpAddr,
dst: IpAddr,
protocol: u8,
fragments: BTreeMap<u16, Vec<u8>>

[Parser trait]
fn parse(&self, data: &[u8]) -> Option<Layer>

[Pipeline]
Capture loop -> parser -> reassembler
Use channel (tx, rx)
Capture loop -> tx -> rx -> parser -> reassembler

[Defragmentation]
IP Packet has an identification field which is the index of the datagram in the list of fragmented packets
It also has a Do Not Fragment flag (second bit) and a More Fragments flag (third bit)
Fragment Offset field: shows the position of the fragment in the original datagram
    Measured in units of 8 bytes, so offset = BYTE_OFFSET/8
